# 🎁 Christmas gift 2026: our explainer skill file

[`explainer-episode/SKILL.md`](explainer-episode/SKILL.md) is the method we use to research, script, check and finish
episodes, written so you can use it yourself. Thank you for watching.

## How to use it
- **With Claude Code:** copy the `explainer-episode` folder into `.claude/skills/` in your project (or `~/.claude/skills/`),
  then type `/explainer-episode <your topic>`.
- **With another assistant, or by hand:** open the file and use it as your checklist.

It contains the method, not our video engine, voice or artwork. An assistant can make mistakes: check facts and licences yourself.
