## How we pick tools
Free, open source or free to use, well known, and actively maintained. No sponsorships and no affiliate links.
Each tool is re-checked on the date shown on its episode page. Tools change: if a link breaks or a tool stops
being free, please open an issue.

## Corrections
Found a mistake? Open an issue with the episode number and a source. We fix and note corrections.
